# 局域网两机验收清单（T-12）

> 版本基线：v2.9（2026-09-09）　·　平台：Windows only　·　配套：[未完成与中断任务清单.md](./未完成与中断任务清单.md)
> 验收目标：两台真实 Windows 设备同一局域网/千兆交换机下，验证 P0-3~P2 全部主链路，
> 传输吞吐达标（**≥80 MB/s** 指标，分块 1 MiB）。
>
> 执行方式：逐条勾选；每条记录「结果（通过/失败）+ 备注」。失败项回到对应 test/代码定位修复后重跑本清单。
> 环境替代：无第二台真机时可用 VMware/Hyper-V 虚拟机兜底（需与宿主机同一虚拟网卡，注意 UDP 广播可达）。
