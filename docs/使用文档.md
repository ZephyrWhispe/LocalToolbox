# LocalToolbox —— 使用文档

> 面向最终用户：安装、界面导航、各功能模块的使用方法与常见问题。
> 版本：v3.5c（2026-09-10）　·　平台：Windows only
> 配套文档：[功能设计文档.md](./功能设计文档.md) · [技术文档.md](./技术文档.md)

---

## 一、简介

「LocalToolbox」是一款 Windows 下的局域网协作工具，主要能力：

| 分组 | 功能 | 说明 |
|------|------|------|
| 协作 | 剪贴板同步 / 键鼠共享 / 文件传输 | 局域网设备间实时协作 |
| 共享服务 | 共享文件夹（SMB）/ Web 服务 / FTP 服务 | 向局域网发布资源 |
| 网盘与代理 | **网盘挂载 / 代理管理**（v3.0 新增） | 聚合访问 40+ 主流网盘、V2rayN 节点代理加速 |
| 工具 | 文件管理 / 网络扫描 / 右键菜单 / 工具箱 / 截图标注 | 日常与运维辅助 |
| 系统 | 设置 | 主题、历史、加密、接收目录等 |

版本 v3.0 新增两大能力，v3.1 对代理管理再次升级：

- **网盘挂载**：内置 OpenList 统一后端 + WebDAV 客户端，一个入口浏览/上传/下载
  阿里云盘、百度网盘、夸克、OneDrive、Google Drive 等 40+ 网盘，支持一键映射为本地盘符；
- **代理管理（V2rayN 集成）**：导入 V2rayN 节点（订阅 / 配置目录 / 分享链接），应用内自跑
  代理核心，自动设置系统代理，节点失效自动切换重连；
- **v3.1 代理管理升级**：三核心切换（Xray / Sing-Box / V2Ray）、代理模式（全局 / 智能分流 /
  直连）、TUN 模式、GeoIP 规则库自动下载、高级路由/DNS 编辑、系统代理四策略（自动配置 /
  PAC / 不改变 / 清除）、实时流量统计与批量测速；
- **v3.2 网盘挂载扩展**：Rclone 本地挂载（把网盘挂成盘符 / 文件夹，Windows 资源管理器直接使用）、
  WinFsp 驱动一键安装、OpenList 服务实时监控（运行时长 / CPU / 内存 / 日志）与一键重启、
  检查更新并自动下载最新版、支持开机自启与随应用恢复挂载；
- 核心组件与规则库（OpenList / xray / v2ray / sing-box / geoip / geosite / rclone / winfsp）
  均支持**自动下载**（内置「自动下载」按钮，从 GitHub Releases 拉取），也可手动放置二进制；
- **v3.3 截图能力增强（参考 ShareX）**：区域截图（拖选任意区域）、GIF 屏幕录制
  （可选 2/5/10 fps）、OCR 识别文字（系统原生引擎，截图或本地图片一键提取文字）、
  屏幕取色器 + 放大镜（全屏拾色并自动复制色值）。

## 二、安装与启动

1. 安装依赖（首次）：`pip install -r requirements.txt`；
2. 启动：`python main.py`（或使用 `build.bat` 打包后的 `LocalToolbox.exe`）；
3. 首次运行在任务栏常驻托盘图标，点击托盘图标或全局快捷键可快速呼出主窗口
   （呼出后自动跳到剪贴板历史页）。默认快捷键：`Ctrl+Alt+V` 呼出剪贴板历史、
   `Ctrl+Alt+A` 区域截图；在「设置 → 全局快捷键」中可自定义，支持 Win+ 组合
   （如 Win+V 被系统占用时自动钩子接管，退出本应用后系统恢复原样）。

数据均保存在本机 `%APPDATA%\LocalToolbox\`（配置、日志、网盘与代理数据都在其中，
设置页有「打开数据目录」入口）。

## 三、界面与导航

主窗口分四区：顶部标题栏、左侧导航、中部内容区、右侧设备面板（底部状态栏）。

导航按功能逻辑分为五组（v3.0 起定稿）：

```
协作        剪贴板 / 键鼠共享 / 文件传输
共享服务    共享文件夹 / Web 服务 / FTP 服务
网盘与代理  网盘挂载 / 代理管理        ← 新增
工具        文件管理 / 网络扫描 / 右键菜单 / 工具箱 / 截图标注
系统        设置
```

点击左侧任意条目进入对应页面；窄窗口下可点左上角按钮展开抽屉式导航。
右侧设备面板展示局域网内发现的本机/其他设备，可对设备执行发送文件、连接键鼠等快捷操作。

## 四、网盘挂载（新增）

入口：左侧导航 **网盘与代理 → 网盘挂载**。

### 4.1 首次使用（三步）

1. **准备后端**：
   - 推荐点卡片「自动下载」让应用帮你拉取 OpenList 程序（需联网，网络不佳可手动下载后
     点「选择...」指定 `openlist.exe`）；
   - 二进制备好后「启动」服务，等待状态变为「运行中（健康✓）」。默认监听 `127.0.0.1:15244`，
     端口可改（改动后需重启服务）。
2. **配置网盘授权**（二选一）：
   - 服务运行后点「打开管理界面」，在浏览器中按引导为新网盘添加账号并完成授权/登录；
   - 或点「导入配置」选择已有的 `openlist.json`（从其他 OpenList 安装导出），
     导入后重启服务生效。
3. **开始使用**：在下方文件浏览器中浏览网盘内容，上传/下载、新建文件夹、重命名、删除。

### 4.2 常用操作

| 操作 | 方法 |
|------|------|
| 浏览 | 文件列表单击选中，双击文件夹进入；面包屑点击可返回上级 |
| 上传 | 点「上传」选择本地文件，传至当前所在目录（任务列表显示进度，可取消） |
| 下载 | 选中文件点「下载」，默认保存到系统下载目录（可在任务列表看进度） |
| 新建文件夹 | 「新建文件夹」输入名称 |
| 重命名 / 删除 | 先选中条目再操作；删除需二次确认，不可恢复 |
| 映射盘符 | 在「盘符映射」输入框填盘符（如 `N:`）点「映射」，
  Windows 资源管理器中立即出现该网盘盘符；「取消映射」移除 |
| 多任务 | 上传/下载并发 2 个任务，每个任务可单独取消 |

> 提示：网盘内容经本地 WebDAV 接口读写，速度取决于网盘与本地网络；上传下载大文件时
> 建议保持服务运行，切勿直接结束进程。

### 4.3 本地挂载（盘符 / 文件夹，v3.2）

不满足于页内浏览时，可把 OpenList 网盘**挂载为本地盘符或文件夹**，之后在资源管理器、
任何软件中像本地磁盘一样直接读写（依赖 rclone + WinFsp 驱动）：

1. **备齐依赖**（上方卡片）：确认「WinFsp 驱动」已安装（未装点「安装 WinFsp」自动下载安装，
   非管理员会弹出 UAC 确认）；确认 rclone 已就位（没有点「自动下载」）；
2. **填入目标与账号**：目标类型选「盘符」（填单个字母，如 `V`，需未被占用）或「文件夹」
   （填绝对路径，如 `D:\pan-mount`）；账号/密码留空 = 匿名，一般与 OpenList 后台一致；
3. 点「挂载」——成功后盘符/文件夹即可用；「当前挂载」列表可一键卸载。

> 提示：挂载为盘符走免管理员模式；若挂载长时间未生效会自动报错并给出 rclone 日志尾部提示。
> 勾选「随应用恢复挂载」后，每次启动应用会自动把上次的挂载重新挂上。

### 4.4 服务监控与更新（v3.2）

- **实时监控**：服务卡显示 OpenList 运行时长、CPU、内存与当前驱动数，异常退出会自动复位；
- **重启**：改了端口/配置后点「重启」一键生效，不用手动停再启；
- **查看日志**：快速排查——滚动查看 OpenList 最新日志尾部；
- **检查更新**：一键查询 OpenList / rclone 的 GitHub 最新版本（同时显示本地缓存版本），
  点「下载」即拉取最新版（有本地缓存自动跳过重复下载）；
- **自启动**：
  - 「网盘挂载」页：`OpenList 随应用启动`（打开本应用即自动启动 OpenList）、
    `启动后恢复挂载`（自动重挂上次的 rclone 挂载）；
  - 「设置」页「自启动」卡：本应用**开机自动启动**（登录 Windows 后后台常驻，托盘可用）。
- **自动更新**（「设置」页「快捷键与启动」分区）：
  - 开启「**自动检查更新**」后，启动 30 秒检查一次 GitHub 最新版本，之后每天自动检查；
  - 检查范围可选：OpenList / Rclone / 代理核心（当前所选 xray / sing-box / v2ray）；
  - 开启「**自动下载新版本**」后，检查到新版本自动下载到组件目录——**不中断运行中的
    服务，重启 OpenList / 代理服务后生效**；
  - 也可随时点「立即检查」查看各组件"本地版本 → 最新版本"状态，或点「下载更新」
    只手动更新有新版本的组件；
  - 版本查询与下载走 GitHub Releases（支持镜像加速），同版本自动复用本地缓存。

## 五、代理管理（V2rayN 集成，新增）

入口：左侧导航 **网盘与代理 → 代理管理**。

### 5.1 首次使用（三步）

1. **准备核心**：点「自动下载 xray」（或「选择...」手动指定 `xray.exe` / `v2ray.exe` /
   `sing-box.exe`，程序也会自动探测 V2rayN 安装目录里的核心）。
2. **导入节点**（三选一）：
   - **订阅 URL**：填入机场订阅链接，点「导入订阅」；
   - **V2rayN 目录**：点「从目录导入」选择 V2rayN 安装文件夹（读取节点配置）；
   - **剪贴板**：复制分享链接后点「剪贴板导入」（vless:// vmess:// trojan:// ss:// hy2://
     tuic:// wireguard:// anytls:// 均可，也支持手动粘贴多行）。
   导入成功的节点显示在节点列表（含名称/地址/类型）。
3. **启动代理**：选一个节点（或先点「测试」看延迟），点「启动代理」。
   启动后自动写入系统代理（本机 HTTP 10809 / SOCKS5 10808 端口，可改），
   浏览器及系统网络即走代理线路。

### 5.2 高级能力（v3.1）

- **三核心可切换**：核心类型下拉选 **Xray / Sing-Box / V2Ray**，运行中切换会自动按新核心重启
  当前节点；「自动下载核心」跟随所选核心拉取对应程序；
- **代理模式**：`全局模式`（所有流量走代理）/ `智能分流`（国内+局域网直连，其余走代理）/
  `直连模式`（= 停止核心）；
- **GeoIP 规则库**：智能分流依赖规则库——Xray/V2Ray 用 `geoip.dat/geosite.dat`，
  Sing-Box 用 `geoip.db/geosite.db`；点「下载规则库」一键拉取当前核心所需文件，
  缺失时自动退回内置静态分流（国内网站仍直连）；
- **TUN 模式**：复选框开启（仅 Sing-Box，需**管理员权限**运行本程序，驱动 `wintun.dll`
  随核心自动解出）。开启后接管系统级所有流量，效果类似 VPN；
- **高级配置**：弹出编辑器可直接改 `routing`（v2rayN 自定义路由规则数组或对象）与 `dns`
  JSON，支持广告拦截（如 `geosite:category-ads-all` → block），下次启动生效；
- **系统代理策略**：`自动配置`（启动写入、停止还原，推荐）/ `PAC 模式`（本地
  `pac.js` 分流，局域网直连）/ `不改变`（保留其他软件设定）/ `清除`（启动即清）；
- **流量统计**：运行中显示实时上行/下行速度条（系统级采样，三核心通用）；
- **批量测速**：一键测全部节点延迟并按快慢排序展示，结果回写节点列表。

### 5.3 连接状态与自动重连

- 启动后卡片实时显示当前节点、各节点延迟与健康状态；
- **失败自动切换**（默认开）：当前节点 2 次探测失败即自动切换到下一个节点并重启核心，
  全部节点不可用时自动停止并**还原系统代理设置**；
- 取消勾选「失败自动切换」= 固定使用所选节点，失败只停不换；
- 「系统代理」开关控制启动时是否自动写入系统代理（关闭则仅本应用内手动使用代理端口）；
- 停止代理（或应用退出、核心异常）时会**自动还原系统代理**，不会残留。

### 5.4 节点管理

- 节点列表每行：测试（实时延迟）/ 设为当前 / 删除；
- 节点数据保存在 `%APPDATA%\LocalToolbox\proxy\nodes.json`，删除列表即从本地移除；
- 「数据目录」按钮可一键打开代理数据目录。

## 六、截图与录屏能力增强（参考 ShareX）

入口：**工具 → 截图标注**（区域截图 / 屏幕录制 / OCR）与 **工具 → 工具箱**
（屏幕取色器 / OCR 识别图片）。区域截图与录屏范围选择均为**独立全屏遮罩弹窗**。

### 6.1 区域截图（ShareX 式圈选）

1. 截图页点「区域截图（圈选）」或按全局快捷键（默认 `Ctrl+Alt+A`，可自定义）：
   **每个显示器**各弹出一个覆盖整屏的无边框圈选窗口；
2. 三种圈选方式：
   - **单击**：鼠标移动时自动识别并高亮光标下的窗口，单击即选中整个窗口并立即截图；
   - **拖动**：按住左键拖出任意矩形（实时宽高 + 放大镜精确定位）；
   - **调整**：拖完松手后进入调整模式——拖 8 个圆点手柄改大小、选区内拖动移位、
     在选区外按下重新圈选，`Enter` / 双击 / 「确认」完成，`Esc` / 「取消」放弃；
3. 截图完成后按「截图后自动」任务链处理（见 6.2），默认已自动保存并复制，
   同时载入画布编辑器继续标注；
4. 多显示器全部可选，圈选坐标精确到物理像素（应用已声明 Per-Monitor DPI 感知）；
5. **重拍上次区域**：点「重拍上次区域」按最近一次圈选的区域重新捕获
   （适合反复截同一位置），走「截图后自动」任务链；
6. **屏幕标尺**：点「屏幕标尺」进入测量模式——拖出线段实时显示长度（px）与
   角度（°），可连续测量，`Enter` 清除当前线，`Esc` 退出。

### 6.2 截图后自动任务与延迟截图

- **截图后自动**（截图页捕获栏下方五个复选框，对应 ShareX After Capture Tasks）：
  - 保存文件：截图完成后自动把原图存到截图目录（按日期归档）；
  - 复制到剪贴板：自动把原图写入系统剪贴板；
  - 载入编辑器：自动跳转到截图页画布标注（关闭则仅提示保存/复制结果）；
  - 复制文件路径：自动保存后把文件完整路径写入剪贴板；
  - 定位到文件：自动保存后在资源管理器中定位该文件；
- **延迟截图**：捕获栏「延迟 N 秒」输入秒数后点「全屏截图」/「活动窗口」——
  主窗口自动隐藏，N 秒后截屏并恢复，用于抓取下拉菜单等会随点击消失的界面；
- 全屏截图 = 整个虚拟桌面（多显示器合并为一张图）；活动窗口截图使用 DWM
  扩展边界，不含 Windows 不可见阴影边。

### 6.3 屏幕录制（MP4 视频 / GIF 动图）

1. 截图页「屏幕录制」卡片选择：
   - 格式：**MP4 视频（可录音）** 或 **GIF 动图（低配）**；
   - 帧率：视频 10 / 15 / 30 fps；GIF 2 / 5 / 10 fps（视频最长 30 分钟自动停止）；
   - 范围（视频 / GIF 均可）：整个屏幕，或「自选区域」——点开始后先弹全屏遮罩
     圈定要录的矩形（同一 ShareX 式交互）；
   - 声音（视频）：勾选「同步录制系统声音」，经 WASAPI 回环采集正在播放的声音，
     合并为带 AAC 音轨的 MP4；无有效声音时自动降级为无声视频并提示；
2. 点「● 开始录制」：录制期间**自动隐藏本窗口**（GIF 与视频一致，避免把自己录进去），
   结束后自动恢复；
3. 点「■ 停止」立即结束；编码完成后 Toast 提示保存路径与是否含声音，
   文件在截图目录下：视频 `{日期}_{时间}_rec.mp4`、GIF `…_rec.gif`；
4. 依赖说明：MP4 需要 opencv-python-headless 与 imageio-ffmpeg、comtypes/pycaw
   （`pip install -r requirements.txt`）；缺失时视频入口会提示，GIF 与截图不受影响。

### 6.4 编辑器标注工具

画布上方工具栏：**画笔 / 高亮**（半透明荧光笔，不遮挡内容）**/ 矩形 / 圆形 / 箭头 /
编号**（点击放置递增数字圆圈，重选工具从 1 重新计数）**/ 文字 / 马赛克 / 裁剪**
（拖选后直接裁剪画布）**/ 橡皮**，配颜色、粗细、撤销重做与还原原图；
「从剪贴板导入」可把任意程序复制的图片直接载入编辑器标注；
编辑分辨率上限 4096px，4K 原图无损标注；撤销深度按画布大小自适应
（大图自动减少层级，防止内存占用失控）。

### 6.5 截图历史

列表按时间倒序，每项带**缩略图**：点缩略图或「编辑」载入画布继续标注，
「复制」把原图写回剪贴板，「定位」在资源管理器中显示，「删除」移除文件。

### 6.6 OCR 识别文字

- **识别当前画布**：截图页完成截图（或载入历史图、区域截图）后点「OCR 识别文字」；
- **识别本地图片**：工具箱 → 「OCR 识别图片」→ 选择图片文件；
- 结果弹窗展示识别全文与逐行文本（含坐标/尺寸）：点「复制全文」一键复制，
  点任意行复制该行；
- 使用系统 `Windows.Media.Ocr` 引擎本地识别，不上传网络；中文识别需系统已安装
  中文语言包。若提示「OCR 组件不可用」，请安装 `winrt-Windows.Media.Ocr` /
  `winrt-Windows.Graphics.Imaging`（`pip install -r requirements.txt`）并重启应用。

### 6.7 屏幕取色器 + 放大镜

1. 工具箱 → 「屏幕取色器 + 放大镜」→ 点「开始取色」，全屏进入取色模式；
2. 鼠标移动时实时放大显示指针周围像素，并同步显示 R / G / B 与 HEX 值；
3. 左键锁定当前色：自动复制 `#RRGGBB` 到剪贴板，页面显示 RGB 与 HEX；
4. `Esc` 取消。

## 八、常见问题（FAQ）

**Q1：点「自动下载 xray / OpenList」失败？**
- 多为网络原因：确认本机可访问 GitHub Releases；失败后 Toast 会给出原因与手动放置路径。
  手动方案：从官方 Release 下载 `Xray-windows-64.zip` / `v2ray-windows-64.zip` / OpenList
  Windows amd64 压缩包，解压出 `.exe` 放到 `%APPDATA%\LocalToolbox\proxy\` 或
  `openlist\bin\`，再点「选择...」指定即可。

**Q2：代理启动后无法上网 / 一直显示不健康？**
- 检查：节点是否过期（用「测试」看延迟）、`auto_switch` 是否把所有节点都试过且全失败；
- 若全部失败，程序会自动停止并还原系统代理——到设置里确认系统代理没有被残留写坏，
  必要时手动把 IE 代理关掉再启动；
- 本地端口 10808/10809 若与其它软件冲突，请改端口后重启。

**Q3：网盘列表里没有我想要的网盘？**
- OpenList 驱动需先添加账号：服务运行后点「打开管理界面」在浏览器授权；
- 超过 40 种驱动，未支持的网盘可查看 OpenList 项目说明确认支持列表。

**Q4：映射盘符失败？**
- 需系统支持 WebDAV 挂载（Windows 原生支持）；首次挂载可能要求输入账号密码
  （默认与 OpenList Web 后台一致）；删除已占用盘符或换一个字母再试。

**Q5：关掉程序代理/OpenList 会残留吗？**
- 不会。代理停止/退出自动还原系统代理；OpenList 由应用托管，关闭应用即停止，
  数据完整保留在数据目录，下次启动可继续。

**Q6：端口冲突怎么办？**
- 网盘挂载端口（默认 15244）在「网盘挂载」页修改；代理端口（默认 10809/10808）
  在「代理管理」页修改；均需重启对应服务生效。

**Q7：Rclone 挂载失败？**
- 按提示检查：① WinFsp 驱动是否已装（状态显示「未安装」时点「安装 WinFsp」）；② 盘符是否
  已被占用（换字母或改用文件夹挂载）；③ rclone 是否就位（没有点「自动下载」）；
- 失败会给出挂载日志尾部，留意其中的 rclone 错误行；旧版 WinFsp 若仅盘符挂载失败，
  可改用「文件夹」目标。

**Q8：为什么打开应用后网盘/挂载没有自动起来？**
- 需先在「网盘挂载」页勾选「OpenList 随应用启动」与「启动后恢复挂载」，并在「设置」页
  勾选「开机自动启动本应用」；三档开关独立，逐一打开后重启应用验证。

## 九、安全提示

- 剪贴板/键鼠/文件传输走明文内网协议，请仅在**可信局域网**使用；跨不可信网络请开启
  「设置 → 强制配对加密」；
- 代理节点与订阅属于私有信息，节点库仅存本机；请勿将 `%APPDATA%\LocalToolbox\`
  目录整体分享给他人；
- 网盘授权凭据由 OpenList 加密存储在其数据目录内，删除数据目录即完全清除。
