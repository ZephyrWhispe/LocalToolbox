## 一、总体架构

```
main.py ── pywebview 窗口（webui/index.html）
   │
   ├─ app/bridge/bridge.py  Bridge（聚合所有 *Api Mixin，作为 window 的 js_api）
   │    ├─ base.py          事件推送 emit/app_log、js_api 调用自动日志
   │    ├─ log_api.py       日志状态/调级/打开日志文件
   │    ├─ transfer_api.py  文件传输 + 配对加密 API
   │    ├─ clipboard_api.py 剪贴板同步 API
   │    ├─ km_api.py        键鼠共享 API
   │    ├─ pan_api.py       网盘挂载 API（OpenList + WebDAV，v3.0）
   │    ├─ proxy_api.py     V2rayN 代理管理 API（v3.0）
   │    ├─ …（share/web/ftp/scan/network/file/shellmenu）
   │    └─ bridge.py 内：cfg（config）、discovery（设备发现）
   ├─ app/core/*            业务内核（与 UI 无关，可单测）
   │    ├─ logger.py        统一日志框架（JSON + 异步 + 轮转 + 分级）
   │    ├─ transfer.py      文件传输引擎 + 配对加密传输
   │    ├─ pairing.py       X25519 ECDH + HKDF + AES-256-GCM 配对加密
   │    ├─ discovery.py     UDP 心跳发现与 advertise
   │    ├─ openlist.py      OpenList 进程托管（v3.0，v3.2 增 restart/uptime/性能采样/tail_log）
   │    ├─ webdav_client.py 纯 stdlib WebDAV 客户端（v3.0）
   │    ├─ rclone_mount.py  Rclone 本地挂载（WebDAV→盘符/文件夹，v3.2）
   │    ├─ winfsp.py        WinFsp 驱动检测与提权静默安装（v3.2）
   │    ├─ v2ray_core.py    三核心托管（xray/sing-box/v2ray）+ 节点库 + 系统代理四策略（v3.0~/v3.1）
   │    ├─ traffic.py       流量统计（PowerShell Get-NetAdapterStatistics 系统级采样，v3.1）
   │    ├─ bindl.py         GitHub Releases 二进制自动下载器（核心/规则库/wintun/rclone/winfsp，v3.0~/v3.2）
   │    ├─ ocr.py           Windows.Media.Ocr 系统 OCR 识别（winrt，依赖缺失自动禁用，v3.3）
   │    ├─ pickcolor.py      Tkinter 全屏取色器 + 放大镜（v3.3）
   │    ├─ recorder.py       GIF 屏幕录制（Pillow ImageGrab 轮询取帧 + 分帧编码，v3.3）
   │    ├─ clipboard_sync.py / km_share.py / ftp_* / web_server.py …
   │    ├─ config.py        配置持久化（DATA_HOME）
   │    ├─ single_instance.py / tray.py / firewall.py / runner.py …
   └─ webui/                原生 JS UI（无构建；App 全局命名空间 + 页面注册）
```

约定：
- js_api 方法名 `页面_动作`，均返回 `{"ok":True,"data":…}` / `{"ok":False,"err":"中文"}`；
- pywebview 6：js_api 每次调用在独立线程执行，方法用普通 `def`；
  `window.events.loaded` 后桥接才可 evaluate_js，后台线程推送先缓冲；
- 前端页面注册 `App.registerPage({id,title,icon,group,mount,show})`，
  事件监听放脚本顶层 IIFE（页面未挂载也收），渲染函数带 `#guard` 判空守卫。

## 二、端口与协议

| 端口 | 协议 | 用途 |
|------|------|------|
| UDP 41890 | 心跳广播（JSON，3s 间隔，60s 超时） | 设备发现；beacon 带 `clip_port`/`km_port`/`file_port` |
| TCP 41891 | 每消息一行 JSON + `\n` | 剪贴板文本同步（≤2MB/条，sha1 去重，回声抑制） |
| TCP 41892 | 每消息一行 JSON + `\n` | 键鼠共享事件流（key/move/btn/wheel/control）；连接握手 `hello/welcome` 附带 `screen`(x/y/w/h) 与 `dpi`（v2.9 多目标/屏参交换） |
| TCP 41893 | 帧头 JSON + 二进制负载 | 文件传输（offer/begin/chunk/end/cancel ↔ accept/reject/file_ok/file_fail/summary） |
| TCP 15244 | WebDAV（OpenList） | 网盘挂载（v3.0）：WebDAV 客户端经 `http://127.0.0.1:15244/dav` 读写；端口可配置 |
| TCP 10809 / 10808 | HTTP / SOCKS5 代理 | 代理管理中 v2ray/xray 核心本地监听（v3.0，端口可配置，系统代理写入后由应用托管还原） |

文件传输帧：`{"type":..,"bin":N}\n` 后接 N 字节（仅 chunk 帧带负载）。配对加密后：
`{"type":"enc","bin":N}\n` + nonce(12) + AES-256-GCM 密文（含 16B tag）。

## 四、日志系统（v2.2 新增）

统一日志框架 `app/core/logger.py`：

- **级别**：DEBUG / INFO / WARN / ERROR / FATAL（归一自 logging 的 WARNING/CRITICAL）；
- **格式**：一行一条 JSON（`ensure_ascii=False`）：
  `{"ts":"2026-09-08T22:15:46.197","level":"INFO","logger":"app.transfer","func":"start",
    "line":74,"dev":"DESKTOP-XXX","pid":1234,"msg":"文件传输服务已启动 port=41893"
    [,"event":…,"tid":…,"dur_ms":…,"exc":"Traceback…"]}`
- **分级存储**：`logs/app.log` 全量（5 MiB × 3 轮转）+ `logs/error.log` 仅 ERROR/FATAL（1 MiB × 3）；
- **异步防阻塞**：`QueueHandler`（队列 10000，满则丢弃并计数 `dropped`）+ `QueueListener` 后台写盘；
  覆写 `prepare` 保留 `exc_info`（避免 Python 3.12 把回溯拼进 msg）；轮转 rename 带重试（防杀软锁文件）；
- **运行时调级**：`set_level("DEBUG"|"INFO"|"WARN"|"ERROR")`；
- **生命周期**：`main()` 启动 `init_logging(DATA_HOME, "INFO")` + 注入 `set_user(主机名)` +
  `sys.excepthook` 未捕获异常记 FATAL；退出前 `stop_logging()` 保证刷盘。
- **js_api 自动日志**（`bridge/base.py`）：调用记 INFO（不落参数值）、异常记 ERROR（含堆栈）、
  慢调用 ≥2000ms 记 WARN；高频查询（`_get_state`/`_list`/`app_info`/`cfg_get`/`devices_list`/`log_status`）记 DEBUG；
- **模块命名空间**：`app.transfer` / `app.pairing` / `app.clipboard` / `app.kmshare` / `app.discovery` /
  `app.scanner` / `app.share` / `app.firewall` / `app.drive` / `app.ftp` / `app.ftp_client` /
  `app.web` / `app.network` / `app.runner` / `app.tray` / `app.jsapi` / `app.main` 等；
- **查询与分析**：设置页「日志」卡片（级别、app.log 大小、打开日志目录、查看 app.log），
  js_api：`log_status` / `log_set_level` / `log_open_dir` / `log_open_app` / `log_open_data`；
  文本工具分析示例：

```powershell
# 最近 20 条错误（error.log 每行一条 JSON）
Get-Content "$env:APPDATA\LocalToolbox\logs\error.log" | Select-Object -Last 20

# 按模块统计某时段日志条数
Get-Content "$env:APPDATA\LocalToolbox\logs\app.log" |
  ConvertFrom-Json | Group-Object logger | Sort-Object Count -Descending | Select-Object -First 10

# 搜索文件传输模块的告警以上日志
Select-String -Path "$env:APPDATA\LocalToolbox\logs\app.log" -Pattern '"logger": *"app\.transfer".*"level": *"(WARN|ERROR|FATAL)"'
```

- **敏感信息**：日志不落参数值（js_api 调用仅记参数个数）；剪贴板内容、配对 PIN、明文口令不入日志。

## 八、安全边界

- 明文传输仅限可信内网；跨不可信网络请开启「强制配对加密」（require_pairing）；
- 配对：X25519 ECDH（临时×临时 PFS + 长期×长期身份认证）+ HKDF 派生会话密钥（AES-256-GCM），
  SAS=PIN 6 位人工核对防 MITM；信任表持久化（trusted.json）；
- 文件传输：接收目录隔离 + 相对路径穿越校验 + 重名改名不覆盖 + 逐次确认/自动接收开关；
- 共享/防火墙提权命令参数白名单化，防 cmd/bat 注入；
- 截图：`shot_save` 的 label 经 `_safe_label` 清洗（去 `\/:*?"<>|` + 截断），`shot_delete` 限定截图目录内文件；
- OCR / 录制 / 取色（v3.3）：OCR 仅识别用户显式提交的图片（画布 data URL 或选择的本地文件），
  引擎为系统 Windows.Media.Ocr、无网络上传；GIF 录制纯本地内存累积帧（上限 1200 帧自动停止）；
  取色器为 Tkinter 全屏窗口，锁定后仅写入本机剪贴板；
- 剪贴板图片：DIB 像素流严格按 BITMAPINFOHEADER 校验（宽/高/位深，像素数上限 5000 万防解压炸弹），
  解码失败即丢弃；接收端哈希一律本地重算（不信任对端 hash）；图片落盘独立目录
  `%APPDATA%/LocalToolbox/clipboard_images`；消息超接收端缓冲上限（base64 后）不跨设备推送；
  回声抑制哈希带 60s TTL 自动清理；
- 剪贴板历史加密（v2.9）：`clip_encrypt` 开启后历史 text 以 AES-256-GCM（随机 iv）加密落库
  （前缀 `enc:v1:`），密钥为 32B 随机数经 DPAPI（CryptProtectData，仅本机当前用户可解）保护存
  `clip_enc.key`；密钥缺失/变更时密文条目标 `enc_lost` 显示为空不泄露原文；
- 键鼠共享（v2.9）：多目标为控制端发起的直连（一方主动 attach），边缘切换需显式配置邻居表，
  不允许任意设备被动接管；控制焦点通过 control 消息显式迁移（旧端释放、新端接管）；
- 日志不落参数值、剪贴板内容、口令等敏感信息。
