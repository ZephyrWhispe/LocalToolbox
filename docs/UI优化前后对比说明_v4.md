# UI 全面优化前后对比说明（v4）

> 审查范围：全部 15 个注册页面（含右键菜单页）+ 对应桥接层 API 逐字段核对 + 设计体系一致性检查。
> 方法：4 组并行代码审查（前端渲染逻辑 × 后端返回字段逐项比对）→ 分级修复（功能级 → 体验级 → 视觉级）→ 语法检查 + 全量单测 + 真实窗口冒烟遍历。
> 原则：遵循现有设计体系（App.h / card / switch / list-item / tag / hint / sep / empty / subnav / sec，色彩走 CSS 变量），不做推倒重写。

## 四、视觉与一致性（遵循设计规范）

- **硬编码色清除**：密码强度条 `#e5534b/#2da44e/#d4a72c` → `var(--danger)/--ok/--warn`（暗色主题下不再刺眼）；网盘任务错误条 `--warn` → `--danger`（错误语义归位）。
- **空态换行**：`.empty` 补 `white-space: pre-line`，全部 "第一行\n第二行" 双行空态文案此前塌成一行。
- **补齐缺失样式**：pan 页 7 个自造类（breadcrumb/linkbtn/cur/tasklist/task-wrap/taskbar/task-row）从无定义 → 完整融入设计体系（卡片二级底色、accent 悬停、进度条过渡动画）。
- **截图页**：空黑块画布 → 说明性空态占位，载图后自动隐藏，消除「编辑画布」卡下方大面积空白。
- **布局留白**：共享页首卡补标题「创建共享」+ UAC/访问路径说明，两卡结构上下对齐，缓解整页近半留白。

## 五、后端契约修正（js_api 统一 {ok, data}/{ok, err}）

- `rec_start` 成功返回由顶层散落的 `{ok, fmt, fps}` → `{ok, data:{fmt, fps}}`；`rec_stop` 同理补 data。
- `rec_start` 隐藏窗口异常路径补 `_rec_hidden` 初始化（修复「编码保存中」永久卡死的隐患）。
- GIF 编码未生成文件时结果补 `err` 字段（此前前端只能笼统提示）。
